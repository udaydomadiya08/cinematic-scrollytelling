## 🎧 Sample 01: `kinetix-aether-one-3d-breakdown.html`

* **Subject**: KINETIX // AETHER ONE (Audiophile Hardware Startup Flagship)
* **Live File**: [kinetix-aether-one-3d-breakdown.html](kinetix-aether-one-3d-breakdown.html)
* **Architectural Style**: **S27** (3D Diagonal Explode & Re-Merge Assembly) + **S26** (Interactive Explainer Lab) + **R5** (Sticky Stacking Cards) + **R4** (Dual Velocity Marquee)
* **Stack**: Self-contained HTML5, Tailwind CSS, Three.js WebGL (PBR 3D engine), 2D perspective CAD canvas renderer, Web Audio API synthesizer, zero npm build dependencies.

### Example Prompt:
```text
Create a cinematic scrollytelling website for my audiophile hardware startup called 'KINETIX' and our flagship in-ear monitor 'AETHER ONE'.

Key requirements:
1. Pinned 3D Stage: Begin with the earphone fully assembled and suspended along an engineered 38.4° diagonal 3D vector.
2. 3D Diagonal Exploded Breakdown: As the user scrolls, rotate the earphone in 3D and explode its 7 internal electronic, power, and acoustic transducer layers along the 38.4° diagonal axis. Show leader-line callout pins and an active telemetry HUD.
3. 7 Sub-Assemblies: Include (1) silicone isolation tip, (2) CNC Grade-5 titanium nozzle, (3) coaxial dual-BA tweeter, (4) 11.4mm pure Beryllium dynamic driver with copper coil and N52 magnet, (5) 4-layer ENIG gold flex PCB with KX-DSP2 neural chip, (6) 65mAh curved solid-state Li-Si battery, and (7) Grade-5 titanium unibody shell with smoked sapphire touch faceplate.
4. Magnetic Re-Merge: As the user scrolls through the breakdown, magnetically re-converge all 7 modules back into the unified chassis with an acoustic lock shockwave.
5. Deep Business & Technical Sections: Follow with a scroll-driven dual marquee, letter-by-letter manifesto, a clinical cleanroom inversion seam (#F3F3EE), an interactive 7-layer BOM explorer, a real-time neural ANC simulation lab with live waveform canvas, sticky stacking product/business cards, and an interactive finish configurator (Obsidian PVD, Raw Titanium, Founders 18K Gold).
6. Format: Output as a single, self-contained HTML file that runs directly in any modern browser without npm dependencies.
```

## 🔄 Adapting These Prompts for YOUR Topic

You can adapt any of these prompts for whatever you want to build:

1. **For Hardware & Physical Products (Watches, Drones, Gadgets, Motors, Bikes)**:
   - Use the **S27 Explode & Re-Merge** pattern from [Sample 01](kinetix-aether-one-3d-breakdown.html) or [Sample 04](vantage_ceramica_morbi_1220_c_sintered_architectural_slabs_s27_scrollytelling.html). List your 5–8 physical components, specify the 3D diagonal angle, and state the re-merge closure.

2. **For Science, Nature & Space (Black Holes, Mars, Oceans, Climate, Biology)**:
   - Use the **S02 Planet Hop**, **S18 Zoom-Through**, or **S26 Explainer Lab** pattern from [Sample 02](mars-unfinished-terraforming-story.html) or [Sample 03](singularity_interactive_scrollytelling_guide_to_black_holes.html).

3. **For Culture, Entertainment & Games (Films, Anime, Music, Books)**:
   - Use the **S10 Type-as-Window** and **S17 Particle/Shader** pattern from [Sample 05](hinokami_demon_slayer_kimetsu_no_yaiba_complete_scrollytelling_chronicle.html).
